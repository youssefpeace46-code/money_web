# ساوم

نسخة أولى محلية بالعربية، تعمل دون تثبيت برامج أو مكتبات أو الاتصال بالإنترنت.

## فتح المعاينة

افتح ملف **index.html** بالنقر المزدوج عليه داخل هذا المجلد. سيفتح في المتصفح مباشرة. يُفضّل متصفح حديث مثل Chrome أو Edge أو Firefox. بعد تعديل الملفات، أعد تحميل الصفحة لرؤية التغيير. لا حاجة إلى خادم أو أوامر تشغيل.

المجلد الذي أُنشئت فيه النسخة هو `C:\Users\youuf\Desktop\moneyweb`، وهو المجلد المفتوح أثناء التنفيذ.

## جرّب الموقع

- تظهر ستة عروض وهمية وأسعار وأوقات توضيحية، وليست معلومات سوق حالية. التواصل مع العروض الوهمية معطّل، ولا تحتوي على أرقام أشخاص.
- جرّب البحث والفئات ومرشحات المدينة ونوع العرض. تعمل جميع المرشحات معًا.
- اضغط **أضف عرضك**، أدخل البيانات، ثم راجع العرض وأكّد إظهار رقم واتساب قبل الإضافة.
- للصكوك والحوالات، المبلغ والسعر الإجمالي بالدينار الليبي. للعملات، السعر هو سعر الوحدة بالدينار الليبي.
- يدعم حقل الهاتف أرقام الموبايل الليبية المحلية والدولية، والأرقام الدولية مسبوقة بـ + أو 00. التحقق من الصيغة لا يثبت ملكية الرقم أو وجوده على واتساب.
- تُحفظ عروضك في `localStorage` داخل المتصفح نفسه وتظهر فورًا. لا يراها أشخاص آخرون. يمكنك حذفها بزر **حذف عرضي**.
- قد يقيّد المتصفح التخزين عند فتح الملفات المحلية أو في الوضع الخاص. إذا تعذّر الحفظ تظهر رسالة، ويستمر العرض مؤقتًا في الجلسة الحالية. مسح بيانات المتصفح أو نقل الملفات أو تغيير المتصفح قد يفقد العروض المحفوظة.
- رابط واتساب للعروض المضافة يفتح نافذة جديدة برسالة جاهزة؛ يحتاج استخدام واتساب إلى الإنترنت. لا تُرسل الرسالة تلقائيًا.
- يمكن إيقاف الشريط المتحرك، ويحترم الموقع إعداد تقليل الحركة في جهازك.

## الملفات

- `index.html`: هيكل الصفحة ونموذج إضافة العرض.
- `styles.css`: الألوان والتنسيق وتصميم الهاتف والشاشات الكبيرة.
- `app.js`: العروض والبحث والتحقق والحفظ المحلي وروابط واتساب.

## طلب تعديلات من Codex

افتح هذا المجلد في Codex أو VS Code، ثم اكتب التغيير مباشرة، مثل: «اجعل البطاقات أكبر على الهاتف» أو «غيّر اللون الرئيسي إلى الأزرق الداكن». يمكن إرفاق لقطة للشاشة لتوضيح الشكل المطلوب. أعد فتح `index.html` أو حدّث الصفحة بعد التعديل.

هذه معاينة فقط: لا قاعدة بيانات أو تسجيل دخول أو خدمة دفع أو نشر عام. الموقع يعرض العروض ولا ينفّذ الصرف أو يضمن الأسعار والأطراف والمعاملات. بيانات التواصل في التذييل مكان مخصص للإضافة مستقبلًا.

## الواجهة الحالية: ساوم

الهوية: **ساوم — بواسطة القلعة للصرافة**. الترويسة والخلفية بلون `#181F29`، والعروض قائمة خفيفة بفواصل `#374151`. السعر 26px، وأسماء أصحاب العروض 18px. بقيت الأقسام والفئات ومنطق إضافة العروض والتخزين والتحقق وروابط واتساب كما هي.

- `index.html`: الاسم الجديد في العنوان والوصف والترويسة والتذييل والنصوص، الشعار وfavicon من `assets/logo.png`، وسعر مختصر مع التاريخ الموجود.
- `styles.css`: ألوان داكنة بمتغيرات مشتركة، تسلسل بصري للسعر والكمية، أعلام صغيرة، وتنسيق النموذج والهاتف.
- `app.js`: عرض أعلام العملات، الاسم التجاري داخل رسالة واتساب فقط، اختصار نص تاريخ السعر، وإزالة الاعتماد على مقارنات تجريبية لاتجاه السعر. لم يتغير مفتاح التخزين أو التحقق أو الإرسال.
- `assets/logo.png`: الصورة الأصلية نفسها؛ صُحح اسم الملف من `logo.png.png` دون تغيير محتواه. أزيل استخدام الشعار السابق `logo.svg` وحُذف الملف الذي أضيف في التحديث السابق.
- `assets/flags/*.svg`: أعلام محلية خفيفة لـ USD وEUR وGBP وTRY وTND وLYD، لأن رموز أعلام Emoji لا تظهر كأعلام على بعض أنظمة Windows. خريطة العرض في `currencyFlags` لا تضيف فئات تداول جديدة.

### بيانات السعر

القيمة اليدوية الموجودة هي `9.50 د.ل` بتاريخ `2026-09-23`. لم تُضف أسعار أو أوقات جديدة. لا توجد ساعة تحديث، لذا يُعرض التاريخ فقط. بقيت أمثلة النشرة والعروض الموجودة موسومة بأنها تجريبية.

لا توجد أسعار سابقة موثوقة لحساب الاتجاه. أزيلت قيم المقارنة التجريبية السابقة، ولا تظهر أسهم في البيانات الحالية. تدعم `updateTickerTrends()` حالات `up` و`down` و`unchanged` عند تزويد عناصر `.ticker-price` بقيمتي `data-current` و`data-previous` صحيحتين؛ لا يظهر سهم عند غياب البيانات أو تساوي القيم. هذه مقارنة عرض فقط ولا تضيف مصدر أسعار أو اتصالًا بقاعدة بيانات.

### المعاينة المحلية

افتح `index.html` مباشرة في متصفح حديث، ثم استخدم `Ctrl+F5` بعد التعديل. أو في VS Code انقر على `index.html` بزر الفأرة الأيمن واختر **Open with Live Server**. المنفذ الافتراضي للإضافة المثبتة هو **5500**، فتكون المعاينة عادة على `http://127.0.0.1:5500/index.html` ما لم تغيّر إعداد المنفذ أو يكن مشغولًا. اختبارات الواجهة نُفذت بفتح الملفات محليًا دون خادم.

لا تتضمن هذه النسخة أصلًا Supabase أو لوحة إدارة أو Manifest أو Service Worker، ولم تُضف أو تُعدّل أي إعدادات لهذه الخدمات. favicon يستخدم الشعار الأصلي PNG؛ لم تُنشأ أيقونات PWA أو شعار بديل.

تم التحقق في Chrome من عروض 360 و390 و412 و1280 بكسل: 92 تحققًا ناجحًا تشمل عدم تجاوز العرض، توافق ألوان الترويسة، تحميل الشعار والأعلام، أحجام الأسعار، حالات الاتجاه ببيانات اختبار معزولة، التصفية، مراجعة العرض وإضافته وحفظه وحذفه، وصحة رابط واتساب. لم تُرسل رسائل واتساب أثناء الاختبار.
